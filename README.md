#Employee Beer Preferences App

## What the app is

A lightweight internal web app that lets employees select and display their favorite beer.

It’s designed as a fun profile enhancement rather than a serious HR system, with an emphasis on clarity, usability, and polish.

---

## What it does

- Displays employee profile cards
- Allows employees to choose a favorite beer from a short list
- Updates selections instantly on screen
- Uses friendly placeholders to guide users when no beer is selected

---

## Why it’s useful

- Demonstrates how even small internal tools can feel polished and intuitive
- Focuses on a clear, responsive, and pleasant user experience
- Avoids unnecessary complexity while still feeling complete

---

## Technology (high-level)

- A single app handles both the user interface and the backend, making it simpler to build and maintain
- Updates appear immediately, creating a fast and responsive feel
- Data is temporary by design, keeping the project lightweight and focused

---

## Key takeaway

This project highlights strong UX thinking, smart technical tradeoffs, and clean structure.

It’s less about beer, and more about building simple tools that people enjoy using.
